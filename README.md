# Логгер вызовов LibC

Этот проект представляет собой механизм для перехвата и логирования стандартных вызовов библиотеки `libc` из любого динамически скомпонованного приложения в Linux. Он предназначен для отладки и системного анализа, особенно для приложений, исходный код которых недоступен.

Система состоит из двух основных компонентов:
1.  **Разделяемая библиотека** (`liblogger.so`), которая использует механизм `LD_PRELOAD` для перехвата вызовов функций.
2.  **Демон** (`daemon`), который собирает логи от одного или нескольких приложений в реальном времени и записывает их в лог-файлы.

Взаимодействие между библиотекой и демоном осуществляется эффективно и с минимальными накладными расходами с использованием разделяемой памяти System V и семафоров.

## Возможности

*   **Перехват функций**: Перехватывает вызовы `файлового ввода/вывода` и `управления памятью`.
    *   **Файловый ввод/вывод**: `open`, `close`, `lseek`, `read`, `write`
    *   **Память**: `malloc`, `free`, `realloc`
*   **Высокая производительность**: Использует кольцевой буфер в разделяемой памяти для неблокирующего логирования с низкой задержкой.
*   **Поддержка нескольких процессов**: Демон может собирать логи от нескольких клиентских приложений одновременно.
*   **Демонизация**: Демон-логгер может работать как полноценный фоновый процесс.
*   **Человекочитаемые логи**: Логи включают высокоточную временную метку, ID процесса (PID), имя процесса, а также подробные параметры и возвращаемые значения функций.
*   **Настраиваемость**: Частота опроса демона и пути к лог-файлам настраиваются через аргументы командной строки.
*   **Пакетирование**: Включает конфигурацию CPack для сборки `.deb` пакета для простого развертывания.

## Требования

*   Операционная система на базе Linux
*   `gcc` или `clang`
*   `cmake` (версии 3.10 или выше)
*   `make`
*   `git`

## Как собрать

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <url-репозитория>
    cd logger_for_libc
    ```

2.  **Создайте директорию для сборки:**
    ```bash
    mkdir build
    cd build
    ```

3.  **Сконфигурируйте проект с помощью CMake:**
    ```bash
    cmake ..
    ```

4.  **Скомпилируйте код:**
    ```bash
    make
    ```
    Это создаст библиотеку `liblogger.so` и исполняемый файл `daemon` в директории `build`.

## Как использовать

Для сбора логов необходимо сначала запустить демона.

### Шаг 1: Запустите демона-логгера

Демона можно настроить для логирования вызовов ввода/вывода, работы с памятью или обоих типов. Он также может работать в фоновом режиме.

```bash
# Логировать и ввод/вывод, и память в разные файлы, и запустить в фоне
./build/libc-logger-daemon --type=all --io-log=io.log --mem-log=mem.log &
```

**Опции демона:**
*   `--type=<тип>`: Указывает, что логировать. Может быть `io`, `mem` или `io,mem`.
*   `--io-log=<путь>`: Путь к файлу для логов ввода/вывода (по умолчанию: `io.log`).
*   `--mem-log=<путь>`: Путь к файлу для логов памяти (по умолчанию: `mem.log`).
*   `--interval=<мс>`: Интервал опроса в миллисекундах (по умолчанию: 500).

### Шаг 2: Запустите приложение с логгером

Используйте переменную окружения `LD_PRELOAD` для загрузки библиотеки-логгера перед запуском любого приложения.

```bash
# Пример: Запустить 'ls -l' и залогировать его вызовы libc
LD_PRELOAD=./build/liblogger.so /bin/ls -l

# Пример: Запустить предоставленное тестовое приложение
LD_PRELOAD=./build/liblogger.so ./build/test
```

### Шаг 3: Проверьте логи

Лог-файлы, указанные при запуске демона, теперь будут содержать собранные данные.

```bash
cat io.log
cat mem.log
```

## Как создать пакет

Вы можете создать пакет Debian (`.deb`) с помощью CPack.

```bash
# Находясь в директории 'build'
make package
```

Это создаст файл вида `logger-for-libc-1.0.0-Linux.deb` в директории `build`.
